Bagaimana Cara Testing Responsive Design?

Metode 1: Browser DevTools (Recommended)

  1. Buka aplikasi di Chrome/Firefox
  2. Tekan F12 atau Ctrl+Shift+I untuk buka DevTools
  3. Tekan Ctrl+Shift+M untuk Toggle Mobile View
  4. Pilih device dari dropdown atau ubah ukuran secara manual
  5. Refresh halaman (Ctrl+R) untuk lihat responsive design
💡 Tips: Gunakan throttling di DevTools untuk simulasi koneksi mobile yang lambat (Network → Slow 3G)

Testing Checklist per Breakpoint

Very Small Phone (375px)

  • Buttons terlihat besar dan mudah diklik (min 44px)
  • Text tidak kecil (<10px)< /li>
  • Form input tidak auto-zoom saat focus
  • Sidebar tersembunyi (hamburger menu aktif)
  • Konten tidak overflow horizontal

Small Phone (480px)

  • Hero title ukuran 1.1rem atau lebih besar
  • Stats grid single column
  • Admin form labels terlihat jelas
  • Input fields padding cukup (min 10px)
  • Buttons terlihat dengan jarak (~6px padding)
  • Tables horizontal scroll berfungsi

Phone (600px)

  • Section titles ukuran 1rem
  • Cards padding 14px cukup
  • Status pills tidak dipotong (max 150px)
  • Modal dialog width 95vw dan terlihat
  • Navigation tabs bisa di-scroll
  • Font size form label 0.72rem readable

Large Phone (760px)

  • Breadcrumb tidak overflow
  • Modal max-width 90vw berfungsi
  • Import hint text readable
  • Topbar tidak crowded

Tablet (768px - 900px)

  • Grid layouts semi-responsive (mulai 2 kolom)
  • Topbar height adaptive
  • Font size 15px untuk body
  • Sidebar overlay toggle bekerja
  • Formula steps readable
  • Modal box max-width 90vw

Desktop (900px+)

  • Sidebar always visible 260px
  • Main content margin-left correct
  • Grid-2, Grid-3 layouts full width
  • Topbar full width dengan padding 24px
  • No overflow atau horizontal scroll
  • Menu button tersembunyi

Specific Features Testing

Form Inputs

⚠️ Critical: Form inputs harus 16px font size untuk mencegah auto-zoom di iOS
  • Input field tidak auto-zoom saat di-tap di iOS
  • Focus border (gold) terlihat jelas
  • Keyboard tidak menutupi form field
  • Placeholder text readable

Navigation

  • Hamburger menu (768px ke bawah) berfungsi
  • Sidebar overlay muncul dengan smooth animation
  • Sidebar overlay dapat ditutup dengan tap di luar
  • Active nav item highlight jelas

Tables & Lists

  • Tables horizontal scroll pada mobile
  • Column headers tetap visible
  • Status badges tidak dipotong
  • Action buttons tetap accessible

Modals & Dialogs

  • Modal backdrop visible dengan blur
  • Modal box tidak exceed viewport height
  • Close button (X) mudah di-tap
  • Modal scrollable jika content overflow
  • Modal tidak terpotong di samping

Performance & Accessibility Testing

Touch Targets (WCAG 2.1 Level AAA)

  • Semua buttons minimum 44x44px
  • Links dan clickable elements 44x44px+
  • Spacing antar buttons cukup (min 8px)

Keyboard Navigation

  • Tab key navigasi antar form fields
  • Focus outline visible (gold border)
  • Enter key submit form

Performance

  • DevTools: Lighthouse score bagus (>80)
  • No layout shift saat layout berubah breakpoint
  • Smooth scroll behavior
  • Transitions smooth (0.3s)

Developer Tools Shortcuts

Chrome DevTools

F12 atau Ctrl+Shift+I → Buka DevTools
Ctrl+Shift+M → Toggle Device Toolbar
Ctrl+Shift+P → Command Palette (device simulator)
F5 → Refresh halaman
Ctrl+Shift+Delete → Delete Cache & Hard Refresh

Firefox DevTools

F12 atau Ctrl+Shift+I → Buka DevTools
Ctrl+Shift+M → Toggle Responsive Design Mode
Ctrl+Shift+R → Hard Refresh

Safari (MacOS)

Cmd+Option+I → Buka DevTools
Cmd+Option+U → Responsive Design Mode
Cmd+R → Refresh halaman

Issue Symptoms Solution
Auto-zoom on input focus Form field zoom saat di-tap (iOS) Font size ≥ 16px pada input
Horizontal scroll Konten overflow ke kanan Check max-width, overflow hidden

Actual Device Testing

Testing di Real Mobile Devices

💡 Best Practice: Selalu test di real devices jika memungkinkan, terutama:
  • iOS Safari (iPhone)
  • Chrome Mobile (Android)
  • Tablets (iPad, Samsung Tab)
  • Low-end devices (older phones)

Using Android Emulator

1. Download Android Studio
2. Open Android Virtual Device Manager
3. Create/run emulator with desired resolution
4. Open Chrome in emulator → navigate to localhost:port

Using iOS Simulator (macOS)

1. Open Xcode → Devices and Simulators
2. Create new simulator (iPhone 12, 13, etc)
3. Run simulator
4. Open Safari → navigate to localhost:port
